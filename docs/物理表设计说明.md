# 逻辑关系模式与物理表对照

> 物理层字段采用英文 snake_case，逻辑含义与概念 ER / 关系模式一致，主键均为业务主键。

| 逻辑关系 | 物理表 | 主键 |
|----------|--------|------|
| 学院 | college | college_code |
| 专业 | major | major_code |
| 学生 | student | student_no |
| 教师 | teacher | teacher_no |
| 系统用户 | sys_user | username |
| 角色 | role | role_code |
| 用户角色 | user_role | (username, role_code) |
| 课程 | course | course_code |
| 学期 | semester | semester_code |
| 开课计划 | course_offering | offering_no |
| 选课 | enrollment | (student_no, offering_no) |
| 成绩 | grade | (student_no, offering_no) |
| 奖惩 | reward_punishment | record_no |
| 字典类型 | dict_type | type_code |
| 字典项 | dict_item | (type_code, item_code) |
| 审计日志 | audit_log | (log_no, academic_year) |

## 字段对照示例

| 逻辑 | 物理 |
|------|------|
| 学院编号 | college_code |
| 学院名称 | college_name |
| 学号 | student_no |
| 计划编号 | offering_no |
| 登记用户名 | recorder_username |
| 是否删除 | deleted |
| 是否重修 | is_retake |
| 是否锁定 | locked |
| 是否归档 | archived |

完整 DDL 见 [`db/schema.sql`](../db/schema.sql)。
